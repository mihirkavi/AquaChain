# AquaChain Website

## Overview
AquaChain is a static website showcasing a blockchain-based clean water management solution. The site features a modern, responsive design with sections for About, Solution, Technology, Market, and Contact information.

## Project Architecture
- **Type**: Static HTML/CSS/JS website
- **Server**: Python HTTP server (SimpleHTTPServer)
- **Port**: 5000

## File Structure
- `index.html` - Main HTML page
- `styles.css` - Styling and responsive design
- `script.js` - JavaScript for interactivity (navigation, animations, form handling)
- `server.py` - Python HTTP server with cache-control headers
- `AquaChain.png` - Logo image
- Various `.docx`, `.xlsx`, `.pptx` files - Business documentation

## Running the Project
The website runs on a Python HTTP server on port 5000:
```bash
python server.py
```
